# E-Commerce Sales Analysis Dashboard

## Tools Used
- Excel
- Power BI

## Project Overview
Analyzed 9,994 retail transactions to identify sales trends, regional performance, customer segments, and profitability drivers.

## Key Metrics
- Total Sales: $2.30M
- Total Orders: 9,994
- Total Profit: $286K
- Profit Margin: 12.47%

## Key Insights
- West region generated the highest sales.
- Consumer segment contributed the largest share of revenue.
- Technology category showed strong performance.
- South region recorded the lowest sales performance.

## Dashboard Features
- KPI Cards
- Region-wise Sales Analysis
- Category-wise Sales Analysis
- Segment-wise Sales Analysis
- Interactive Slicers
